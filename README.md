**Mireu Workflow**는 개발 생산성 극대화, 멀티 에이전트 자율 협업 파이프라인, 그리고 클라우드 비용 시뮬레이션을 위한 MCP (Model Context Protocol) 도구 생태계를 구축하는 자동화 엔지니어링 조직입니다.

---

## 📌 주요 프로젝트 (Key Projects)
- **`GCP-Calculator-MCP`**: 115+ GCP 서비스 비용 계산, CUD 약정 할인, IOPS 프로비저닝 및 다중 통화 지원 MCP 서버 (Go)
- **`limmireu-agent-system`**: 4대 독립 자율 멀티 에이전트 시스템 (Process Monitor, K8s Monitor, Pentest, SecOps)
- **`auto-docs`**: Gemma 4 LLM 기반 코드 및 Diff 분석 Wiki/문서 자동 배포 엔진
- **`auto-labeling`**: Google Groups 대화 분석 및 토픽 자동 라벨링 서비스
- **`auto-confirm`**: 기획서 및 Figma 파싱 기반 Git Issue / PR 자동 발행 시스템
- **`deploy-mcp`**: 멀티 클라우드 서버리스 환경 추론 및 배포 자동화 엔진
